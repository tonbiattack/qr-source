# スマートフォン写真からの復元

PC上のQRをスマートフォンで撮影し、画像をPCの1フォルダへ集めて復元できます。撮影順や`IMG_0001.JPG`のようなファイル名は使いません。

```bash
qr-source encode ./my-project
qr-source decode ./photos
```

既定で500バイトのチャンク、Q訂正、1080px画像、広いQuiet Zoneを使います。明示的なチャンクサイズは600バイトまでです。PNG/JPG/JPEG（大文字小文字を問わない）を読み込み、通常読取に失敗した画像だけグレースケール・コントラスト補正・2倍拡大・90度単位の回転を試します。

QR全体と周囲の余白を写し、ピントと明るさを確保してください。反射、手ブレ、極端な斜め撮影は避けます。読めなかった画像は表示しますが、必要なQRが揃っていれば復元を続行します。
